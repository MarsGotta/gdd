# Recipes

What an area usually needs, for the skills to start from. `gdd-prepare` opens the recipe of the product's area before it proposes the gates, and `gdd-checks` before it writes the tests of a change or sets up the standing checks. A recipe is a starting point and never a list to impose: the person, or their team, decides the gates.

- [software.md](software.md): where each test goes, for any product that is software.
- [web.md](web.md): what usually goes wrong on the web, what to start with, what to add when something slips through, and the traps of setting its tests up.

A kit, which the engine will bring, is the whole of an area: its configuration, its standing checks, its tools and its recipes.
