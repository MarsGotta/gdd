Merge Gate: the G3 commands of gdd/commands.toml, Path Guard and the scenario count. Saves the
result next to the change, logs it and prints it as JSON. An agent gdd started (GDD_ROLE)
cannot run it.

## Usage

```text
Usage: gdd g3 [OPTIONS] [CHANGE]
```

## Arguments

| Argument | Description |
|---|---|
| `[CHANGE]` | Id of the change (its record is .gdd/changes/<id>/change.json); else GDD_CHANGE. |

## Options

| Option | Description |
|---|---|
| `--role <ROLE>` | Role Path Guard judges (builder-build also gets the scope check). Default: `builder`. |
| `--strict` | Exit with code 1 when the gate fails. |

## Who runs it

[`gdd launch`](launch.md), after Build, and CI, through [`gdd ci`](ci.md).
An agent that gdd started cannot run it: see
[What an agent may run](../roles.md#what-an-agent-may-run).

## Examples

Without `--strict` it exits with 0 whatever it found; `ok` holds the result.

```bash
gdd g3 cart-total
```
