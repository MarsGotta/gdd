Al instalar

SíntomaCausaQué te toca
La lista de plugins no muestra gddNo está instalado, o el agente es anterior al mínimoActualiza el agente y reinstala con la orden de Empieza.
El plugin aparece, pero el agente no conoce GDDLa sesión abierta no carga plugins nuevosCierra la sesión y abre otra.
El agente dice que falta RustLa capa necesita Rust 1.89 o posteriorInstálalo y díselo. Sigue donde estaba.
No hay red para compilarLa primera vez descarga de crates.ioDale red una vez. Nunca bajes una capa ya compilada.
