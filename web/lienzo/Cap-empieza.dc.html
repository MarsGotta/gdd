Empieza

Instala las skills y haz tu primer cambio en cinco pasos.

Preparar, parada 1 de 4

Lo que necesitas

  • Un repositorio con git 2.38 o posterior.
  • Un agente con skills: Claude Code 2.1.275 o posterior, Codex o Antigravity.
  • Rust 1.89 o posterior, para compilar la capa. La primera vez necesita red.
  • macOS o Linux. En Windows no está probado.

1. Instala el plugin

En Claude Code, dentro de una sesión:

/plugin install gdd --marketplace MarsGotta/gdd

En Codex, en la terminal:

codex plugin marketplace add MarsGotta/gdd
codex plugin add gdd@gdd

En Antigravity, en la terminal, desde la carpeta donde quieras guardar el repositorio de GDD, no desde dentro de él:

git clone https://github.com/MarsGotta/gdd
agy plugin install gdd

2. Comprueba que ha entrado

En la terminal, no dentro de la sesión: claude plugin list, codex plugin list o agy plugin list tienen que mostrar gdd. Si aparece pero el agente no lo nota, cierra la sesión y abre otra.

3. Prepara GDD en tu proyecto

Abre el agente en la carpeta del proyecto, con su modelo más capaz, y dile:

Prepara GDD en este proyecto

Genera gdd/blueprint.md y gdd/constitution.md y compila la capa en .gdd/gdd. Revísalos, apruébalos y, si tienes plataforma, configura la protección de rama y el CI como te indica. Ningún cambio empieza hasta que están en la rama principal.

4. Pide tu primer cambio

Añade un filtro por talla al catálogo

Si es verde, no pregunta. Si es amarillo o rojo, con la plantilla del plano, te manda las reglas antes de construir, en menos de 200 palabras (250 en rojo), salvo que pidas más detalle. Confirmas o corriges.

5. Míralo pasar las puertas

Cuando el cambio entra, tu agente te lo cuenta en dos o tres frases. El detalle de una comprobación solo llega si falló o si lo pides. Si un test falla, el agente lo corrige y repite. En rojo, con la plantilla, la revisión final es tuya, en la pull request de tu plataforma si la tienes, con las pruebas que te deja el vigilante.

No es eso. Basta con cerrar la sesión y abrir otra: la sesión abierta no carga plugins nuevos.
