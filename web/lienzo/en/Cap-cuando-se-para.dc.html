When it stops

Symptom by symptom: what happened and what your part is.

Execute, stop 2 of 3

When installing

SymptomCauseYour part
The list of plugins doesn't show gddIt isn't installed, or the agent is older than the minimumUpdate the agent and install it again with the command in Get started.
The plugin shows up, but the agent doesn't know GDDThe open session doesn't load new pluginsClose the session and open another.
The agent says Rust is missingThe layer needs Rust 1.89 or laterInstall it and tell it. It picks up where it was.
There's no network to buildThe first time, it downloads from crates.ioGive it network once. Never download a ready-built layer.

During a change

SymptomCauseYour part
It waits for your approvalThe blueprint asks for a personRead it and approve it. No agent can do it for you.
@assumed on a ruleThe agent chose itCorrect it if it isn't yours.
@question on a ruleThe answer can waitNothing for now.
A check failsThere's a fix roundNothing, unless a limit runs out.
fix from the reviewerSomething has to be corrected firstNothing. The sealed tests it names get corrected first, and the builder takes the rest.
stop from the reviewerThe change doesn't go inRead the reason.
The color risesIt touched something more delicate and goes back to BriefApprove the new brief, if its color asks for it.
The seal check failsSomeone touched what judges the changeThe change stops and the agent tells you.
A limit runs outAttempts, time or cost were used upYour agent tells you what works and what's missing, and proposes a way out. .gdd/gdd limits <id> shows what was spent.
Something unrelated to the change failsDebt not recorded in gdd/debt.md, or an unstable checkYou decide, or your team does: record the debt or put the check in quarantine.
An emergency to skip a checkSkipping it loosens itWhoever the blueprint names approves it. It goes in the log.

With the layer

SymptomCauseYour part
The layer refuses a stepA step out of order, or a file changed after sealingNothing. The layer says what to run.
In CI the layer refuses everythingThe container checks the repository out as another userAdd git config --global --add safe.directory "$PWD" before it.
gdd verify --all fails in CIA broken log or a hash that doesn't matchHand the line to the agent. Don't edit the log by hand.
