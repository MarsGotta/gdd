Get started

Install the skills and make your first change in five steps.

Prepare, stop 1 of 4

What you need

  • A repository with git 2.38 or later.
  • An agent with skills: Claude Code 2.1.275 or later, Codex or Antigravity.
  • Rust 1.89 or later, to build the layer. The first time, it needs the network.
  • macOS or Linux. It hasn't been tested on Windows.

1. Install the plugin

On Claude Code, inside a session:

/plugin install gdd --marketplace MarsGotta/gdd

On Codex, in the terminal:

codex plugin marketplace add MarsGotta/gdd
codex plugin add gdd@gdd

On Antigravity, in the terminal, from the folder where you want to keep the GDD repository, not from inside it:

git clone https://github.com/MarsGotta/gdd
agy plugin install gdd

2. Check it's in

In the terminal, not inside the session: claude plugin list, codex plugin list or agy plugin list have to show gdd. If it's there but the agent doesn't notice it, close the session and open another.

3. Set GDD up in your project

Open the agent in the project's folder, on its most capable model, and tell it:

Set GDD up in this project

It generates gdd/blueprint.md and gdd/constitution.md and builds the layer at .gdd/gdd. Review them, approve them and, if you have a platform, set up branch protection and CI as it tells you. No change starts until they're on the main branch.

4. Ask for your first change

Add a size filter to the catalog

If it's green, it doesn't ask. If it's yellow or red, with the blueprint's template, it sends you the rules before building, in under 200 words (250 on red), unless you ask for more detail. You confirm or correct them.

5. Watch it go through the gates

When the change is in, your agent tells you in two or three sentences. The detail of a check only comes if it failed or you ask. If a test fails, the agent fixes it and goes again. On red, with the template, the final review is yours, in your platform's pull request if you have one, with the evidence the reviewer leaves you.

Before you cross: The plugin is on the list, but the agent doesn't know GDD. Do you have to reinstall it?

That's not it. Closing the session and opening another is enough: the open session doesn't load new plugins.
